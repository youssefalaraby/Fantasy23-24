## Fantasy 2023/24 Data Analysis - Project Summary

This project analyzes player data from the Fantasy Premier League (FPL) 2023/24 season. It focuses on providing insights into player performance, 
value, and selection trends using a comprehensive set of statistics. The dataset includes general player information, financial and selection data,
team and position details, and a wide range of performance metrics such as goals, assists, clean sheets, and advanced stats like expected goals (xG) and expected assists (xA).
Rankings and per-90 statistics are also included for deeper analysis.
The project is structured as a Jupyter Notebook and leverages Python libraries such as pandas, numpy, matplotlib, seaborn, and mplsoccer for data exploration, visualization,
and advanced football analytics. Exploratory Data Analysis (EDA) is performed to summarize the main characteristics of the data, identify trends, and support strategic decision-making for FPL managers.
